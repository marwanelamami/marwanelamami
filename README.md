# Marwan Elamami

CS student from Tripoli, Libya. I work on on-device AI — getting capable models to run on phones and edge hardware without a cloud backend.

Most AI research assumes you have a GPU cluster. Most people don't. A farmer in rural Libya, a student with a budget Android, a nurse in a clinic with no stable internet — they all have a smartphone. My goal is making sure AI works there too.

The core problem is a compression and systems one: take a model that was trained at scale, and make it fast, small, and accurate enough to run locally on constrained hardware. That means quantization (INT8/FP16), pruning, knowledge distillation, and runtime optimization using frameworks like ONNX Runtime and TFLite. Every millisecond of latency and every megabyte of RAM matters when your deployment target is a mid-range phone.

I'm also a campus ambassador for Perplexity AI and Replit, and I compete in algorithmic programming on Codeforces when I want to think differently about hard problems.

I don't have a lot of public repos yet — most of my work has been experiments, notebooks, and things I'm still building. That changes soon.
